# Data

Due to repository space constraints, this directory contains compact subsets that preserve the data interfaces used by the task evaluators. The complete datasets used in the experiments are available from the following original sources:

- [WikiText-2](https://huggingface.co/datasets/Salesforce/wikitext)
- [AG News](https://github.com/mhjabreel/CharCnn_Keras/tree/master/data/ag_news_csv)
- [Mini-ImageNet](https://huggingface.co/datasets/GATE-engine/mini_imagenet), with feature extraction and episodic evaluation based on [EasyFSL](https://github.com/sicara/easy-few-shot-learning)
- [PhonemeSpectra](https://timeseriesclassification.com/description.php?Dataset=PhonemeSpectra)
